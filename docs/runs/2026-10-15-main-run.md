## Setup
- Date: 2026-10-15
- Hardware: AMD64 Family 25 Model 33 Stepping 0, AuthenticAMD, 16 logical CPUs, none (CPU only); Windows 10
- Python 3.11.9; numpy 2.4.6, pandas 3.0.6, scikit-learn 1.9.1, xgboost 3.2.0, optuna 5.0.0, shap 0.51.0, matplotlib 3.11.2
- Seed: 42 (hold-out split, tuning samplers, model seeds, bootstrap). Per-fold tuning seeds are derived as `seed + 1000*repeat + fold`.
- Hold-out: 800 train / 200 test rows, stratified; bad rate 0.300 train, 0.300 test.
- Nested CV: 3 repeats x 5 outer folds, 3 inner folds, 20 Optuna TPE trials per model, objective inner-CV log loss.
- Bootstrap: 2000 stratified resamples of the test split.
- Wall clock: nested CV 143.5 s, final fit 33.1 s, evaluate 294.9 s.

```
credit-risk train --seed 42 --trials 20 --splits 5 --repeats 3 --inner-splits 3
credit-risk evaluate --seed 42 --bootstrap 2000
```
